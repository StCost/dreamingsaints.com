# Dreaming Saints

Landing page for [dreamingsaints.com](https://dreamingsaints.com). A workshop front door: the studio, the four games, the three people, and the links already published on the [chronicle](https://dreamingsaints.github.io/blog/).

Static files. Open `index.html` or serve the folder.

## Domain

`CNAME` is set to `dreamingsaints.com`. After GitHub Pages is on for this repo, point the domain at it:

- `A` records `185.199.108.153`, `185.199.109.153`, `185.199.110.153`, `185.199.111.153`
- `AAAA` records `2606:50c0:8000::153`, `2606:50c0:8001::153`, `2606:50c0:8002::153`, `2606:50c0:8003::153`
- or a `CNAME` for `www` to `stcost.github.io`

Add `www.dreamingsaints.com` as well if that host should answer.
